TRIP-GUIDE ・ CLAUDE SKILL

一句話，做出全團都在用的旅遊手冊網頁 🧳

把行程丟給 Claude，它會幫你做一個手機優先的旅遊網頁：集合倒數、每日行程、記帳分帳、分房、推薦清單、留言板。6 種風格任選、全部免費。

🎨 6 種風格

同一個示範旅程（虛構的北海道 6 日家族旅行），換一個設定就換一種長相。點進去可以在畫面下方切換風格。

每個版本都有的貼心設計

⏰ 打開就知道現在要做什麼依當地時間自動跳到今天、標出進行中的行程
🛂 出發前準備步驟卡簽證、入境申報一步一步列好，附官方連結
🗺️ 每段行程一鍵開地圖交通彩色標籤、「必去」標記、分類篩選
📱 加到手機主畫面像 App 一樣一點就開，不用下載
🔒 隱私優先隨機網址、不被搜尋引擎收錄、護照密碼一律不放
🌙 尊重「減少動態效果」插圖會輕輕動，但手機關掉動畫就停

⚡ 怎麼安裝

  1. 準備 Claude Code
    團體版和領隊版需要 AI 幫你上傳網站，要用 Claude Code（Claude 桌面版的 Code 分頁也可以）。只做個人輕量版的話，一般的 Claude 對話也做得出網頁檔。
  2. 把 skill 裝進 Claude
    打開「終端機」，貼上這兩行： 
    git clone https://github.com/Joanne9N/trip-guide-skill.git
mkdir -p ~/.claude/skills && cp -R trip-guide-skill/trip-guide ~/.claude/skills/
  3. 跟 Claude 說你要做什麼
    例如：「幫我們做一個旅遊手冊網頁，7 月去北海道 6 天，一家 8 個人」。它會先問你要哪個版本、哪種風格，再列計畫給你確認。
  4. 需要你親自按的地方，它會停下來
    註冊 Cloudflare、登入授權、設定管理密碼都要你本人操作，不會經過 AI 對話。完整說明在 GitHub 的 README。
